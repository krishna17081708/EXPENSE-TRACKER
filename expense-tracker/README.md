## 💰 Expense Tracker

A responsive personal finance management app built with React and React Router.

### Features
- 📊 Dashboard with total balance, income, expense and savings rate
- ➕ Add, edit transactions
- 📁 Category-wise transaction management
- 📈 Visual reports with income vs expense and category-wise pie charts
- 🔀 Multi-page navigation with React Router

### Tech Stack
- React
- React Router DOM
- Recharts
- Vite
- CSS Grid & Flexbox
